# Missing FastAPI parity

This table lists where fastrapi still differs from FastAPI (reference: `others/fastapi`, 0.162.0, with Starlette from `others/starlette`).

🟡 Partly works, edge cases only, or the option is accepted but has no effect · 🔴 Missing, broken, crashes, or behaves differently in a way an app can hit

Startup fix: ✅ can be fixed at import, route registration, startup or OpenAPI generation with no per-request cost · ❌ needs work on the request path · ❓ not yet decided · — not assessed

## How this list was made

On 2026-11-13 seven read-only audits compared FastAPI and Starlette source, function by function, with fastrapi's Rust and Python code, and probed the behaviour side by side against the real FastAPI 0.162 (separate processes, Starlette `TestClient`). The slices were: the `FastAPI` app class, routing, dependencies and parameters, OpenAPI and encoders, security/responses/middleware, Starlette's `Request`/`WebSocket`/ASGI layer, and telemetry/CLI/packaging.

- The probes ran on a wheel built before the latest uncommitted changes, so a few rows may already be fixed in the source tree. Check a row against a fresh build before working on it.
- Most probes went through Starlette's `TestClient`; behaviour on a real server (teardown timing, threads, FastAPI-side WebSocket spans) is only partly covered. OTLP `auto_configure`, the `fastapi-cli` options and `middleware.wsgi` were not probed.
- 198 rows below (96 🔴, 102 🟡). Rows that no longer reproduced are kept in their own section at the end.

## FastAPI's own test suite

FastAPI's test suite (`others/fastapi/tests`, 542 files, 4,054 tests) was run against fastrapi by mapping `fastapi.*` imports to `fastrapi.*`. Each file ran in its own process.

- 3,123 tests pass and 916 fail or error, a pass rate of **77.3%**.
- About 130 of the failures come from the test environment rather than fastrapi:
  - packages that were not installed: `jwt`, `pydantic_settings`, `email-validator`, `yaml`, `sqlalchemy`, `typer`, `strawberry`, `a2wsgi`;
  - tests of FastAPI internals: `fastapi._compat`, `fastapi.telemetry._asgi`, `fastapi.routing._PING_INTERVAL`.
- Without those, the pass rate is roughly **83%**.
- 96 files pass completely. `test_router_circular_import.py` hangs.

The rows in the "Found by FastAPI's test suite" section below come from these failures. Many rows in the main table are also confirmed by failing suite tests, which are noted there.
